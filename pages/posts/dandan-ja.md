[Dandan](https://dandan.alexvolkihar.ovh)は、漢字の言葉の上にふりがなを描く日本語フォントだ。普通のテキストを渡すだけで読みが出る。`<ruby>`タグもJavaScriptも使わない。さらにJLPTの語彙リストを持っていて、自分のレベルを指定すると、そのレベルとそれより易しいレベルの言葉からふりがなが消える。難しい言葉にはふりがなが残る。

名前は「段々」から取った。フォントはSIL Open Font Licenseで自由に使え、Noto Sans JPをもとにしている。

![Dandanのトップページ：タイトル、ダウンロードボタン、すべての読みを表示した見本](/images/dandan-hero.png)

## きっかけ

Anthony Fuさんの[Furifont](https://furifont.antfu.me)（[ソースコード](https://github.com/antfu/furifont)）は、フォントだけでふりがなを付けるフォントだ。この方法がブラウザで実際に動くことを示したのはFurifontで、ブラウザが漢字とかなを別々のランに分けて処理することも、私はFurifontで知った。Dandanはそれとは別の実装で、PythonとfontToolsで書いた。Furifontとコードは共有していない。

私が加えたかったのは、「もう知っている言葉」を伝える手段だ。すべての言葉にふりがなが付いていると、最初の一週間は助かる。でもそのうち、学校や勉強のように読める言葉の上にも読みが並び続け、行がうるさくなる。N3の人に要るのは「状況」や「対策」の読みで、「日曜日」の読みではない。

## 使ってみる

- サイト、プレイグラウンド、ダウンロード：[dandan.alexvolkihar.ovh](https://dandan.alexvolkihar.ovh)
- ソースコード（ビルドスクリプト、データ処理、テスト）：[github.com/Alexvolkihar/dandan](https://github.com/Alexvolkihar/dandan)

普通のWebフォントと同じように読み込む。ふりがなは行の上の空間に描かれるので、行の高さは十分に取っておく。

```css
@font-face {
  font-family: "Dandan";
  src: url("Dandan.woff2") format("woff2");
}

.jp {
  font-family: "Dandan";
  line-height: 1.7;
}

/* N5とN4の読みを隠す */
.knows-n4 { font-feature-settings: "ss04" 1; }

/* すべての読みを隠す */
.no-furigana { font-feature-settings: "calt" 0; }
```

レベルはスタイリスティックセットで切り替える。`ss05`でN5の言葉、`ss04`でN5とN4の言葉が隠れ、`ss01`ではJLPTのリストにあるすべての言葉が隠れる。そのときふりがなが残るのは、どのリストにも載っていない言葉だけだ。`calt`をオフにすると、ふりがなは全部消える。すべてが一つのファイルに入っているので、別のフォントを読み込まずにレベルを変えられる。

![同じ3つの文：レベルなし、N4まで習得、N2まで習得](/images/dandan-levels.png)

スタイリスティックセットを扱えないアプリ向けには、ビルド時にレベルを固定できる。`--level N4`でビルドすると、最初からN5とN4の読みを隠したフォントになる。

![N3を選んだ見本：階段、いま読みが消えた5つの言葉、コピー用のCSS](/images/dandan-specimen-n3.png)

## 言葉ごとに一つのグリフ

フォントには文の意味がわからない。できるのはグリフの置き換えだけだ。そこで、読み付きの言葉をあらかじめ一つのグリフとして描いておく。漢字を横に並べ、その上に半分の大きさのかなを載せたものだ。言葉が現れると、OpenTypeの合字がただの漢字をこのグリフに置き換える。

各漢字の読みがその漢字の上に収まるときは、それぞれの上に置く（日[に]本[ほん]語[ご]）。収まらないときは、読み全体を言葉の中央に置き、言葉の幅まで詰める。これで隣の言葉にはみ出さない。かなは可変フォントの太めのインスタンス（本文の400に対して600）から取っている。半分の大きさだと、普通の太さでは薄く見えるからだ。

ルールは次の順に働く。

1. `words`：漢字2文字以上の合字。長いものから試すので、「日本」より「日本語」が勝つ。
2. `okurigana`：漢字1文字の後に特定のかなが続くと、その言葉の読みを取る（食＋べなら、食の上に「た」）。
3. `kanji`：漢字1文字に迷いのない読みが一つだけあれば、それを付ける（見るの見に「み」）。
4. `hide N5`〜`hide N1`：リストにある言葉の読み付きグリフを、ただの漢字に戻す複数置換。

隠すルールは、わざと合字の後に置いた。知っている言葉でも、まず最長一致で勝つ必要があるからだ。そうしないと「勉強」は合字にならず、2つの漢字にそれぞれ読みが付いてしまうかもしれない。だから一度読み付きのグリフになり、その後でただの漢字に戻る。

![サイトの仕組みの説明：入力、最長一致、ss05で知っている言葉を元に戻す](/images/dandan-how.png)

## 読みを一つに絞る

データは3つある。JMdictから表記、読み、頻度の目印を、JmdictFuriganaからどのかながどの漢字に乗るかを、yomitan-jlpt-vocabのJLPTリストから言葉ごとのレベルを取っている。

漢字の並びには、読みが複数あることがある。はっきり勝つ読みがあるときだけ、一つを残す。同じJMdictの項目の中では最初の読みが勝つので、「今日」は「きょう」で、「こんにち」にはならない。項目をまたぐ場合は、次の候補より3倍以上よく使われる読みだけを残す。「食」1文字は「た」「く」「しょく」のどれもありうるので、何も付けない。こうして読みなしになる並びは2,166個ある。間違った読みを付けるより、何も付けないほうがいいと考えた。

熟語の中で読みが変わる漢字もある。「都」は単独なら「みやこ」だが、「東京都」では「と」だ。そこで、よく使われる接頭辞や接尾辞が別の読みをする漢字は、単独では読みを付けない。数字の後に来る助数詞（日、月、年、時、本、分、人など）も同じ扱いにした。

## グリフの上限

OpenTypeのフォントに入るグリフは、最大65,535個だ。JIS X 0208（第1・第2水準の漢字6,355字、かな、ラテン文字、記号）とふりがな用のかなに絞ったベースフォントで、7,860個を使う。予備に64個残すので、言葉に使えるのは57,611個になる。

辞書の候補は136,639個あるので、半分以上は入らない。JLPTの言葉を最初に入れ、次にJMdictのよく使われる言葉を頻度順に、最後にそれ以外の言葉を、JIS第1水準の漢字だけで書ける短い言葉から入れる。完成したフォントは65,471グリフで、WOFF2で約1.8MB。よく使われる言葉だけでビルドする（`--dictionary common`）と、約1.3MBになる。

知っている言葉にも合字が要るので、どのレベルでもグリフは同じだ。違うのはルールだけで、6つのビルドの差は数百バイトしかない。

## ブラウザでできないこと

ブラウザは文字の形を決める前に、テキストを文字の種類ごとのランに分ける。「食べる」なら、フォントには「食」と「べる」が別々に届く。送りがなのルールは、2つを一緒に見ることができない。文字列全体を渡せばHarfBuzzはこのルールを適用するし、テストでも確かめている。だがブラウザで働くのは漢字1文字のルールだけで、「食」「行」「話」のように読みが複数ある漢字には、読みが付かない。

改行でも同じことが起きる。「提案」の途中で行が折り返すと、それぞれの半分が別々に処理され、別の読みが付くことがある。Chromiumでは`lang="ja"`と`word-break: auto-phrase`を指定すれば、文節の間で改行される。

## ビルドとテスト

ビルドツールはPythonで約1,300行。Noto Sans JPと辞書をダウンロードしてチェックサムを記録し、読みをまとめ、合成グリフを描き、ベースフォントのGSUBテーブルにルールを足す。最初のビルドでは、絞り込んだフォントと辞書のキャッシュを作る。2回目からは1回1分ほどで終わる。

テストは20個ある。シェーピングのテストでは、ビルドしたフォントをHarfBuzzで動かす。「今日」が読み付きの合字一つになること、「日本語」が「日本」に勝つこと、N5の言葉がN5ビルドでは読みなしで、全部入りのビルドでは読み付きになること、スタイリスティックセットで実行時にレベルが隠れること、`calt`をオフにすると読みが消えること、グリフ数が65,535未満であることを確かめている。

## 制限

- 読みを間違えることがある。フォントに見えるのは漢字の並びで、文ではない。最長一致が切る場所を間違えることもあるし、読みが2つある言葉（人気：にんき／ひとけ）には、いつも多いほうの読みが付く。
- 上に書いた理由で、送りがなのルールはブラウザでは働かない。
- JLPTのレベルは推定だ。2010年以降、公式の語彙リストはない。Jonathan Wallerさんのリストでは「日本」がN3で、「日本語」は載っていない。上の画像で、N2でも「日本語」に読みが残っているのはそのためだ。
- Webフォントとして1.8MBは重い。
- 横書きだけ。縦書きではシェーパーが`calt`を使わないので、ふりがなは付かない。読みはひらがなだけで、JIS X 0208にない漢字を含む言葉には読みが付かない。

大事な読みは、自分で確かめてほしい。Dandanは辞書から推測する、読むための補助にすぎない。
